# Контракт сменной платформы

Это спецификация для AI, который создаст код. Контракт не является существующим пакетом и не утверждает наличие всех функций у каждой площадки.

На ранних этапах реализуется общий интерфейс и dev-адаптер. Настоящий YouTube-адаптер, загрузка его SDK и платформенные проверки добавляются на шаге 11, после согласования контента и баланса. MCP Higgsfield — отдельный инструмент разработки графики, подключаемый на шаге 0.

## Граница

App получает готовый `platform` при создании. SaveService, AudioService и AdService используют его интерфейс. Только `src/platform/youtube/` знает `ytgame`, URL SDK и его callbacks. Платформенный bootstrap и Vite-профиль тоже находятся на этой границе. Будущая замена SDK не должна требовать поиска `ytgame` по всем сценам.

| Внутренняя операция | Результат / событие | Владелец игровой логики |
|---|---|---|
| `init()` | capabilities + начальное audio/paused состояние | App |
| `firstFrameReady()` | Уведомление, один раз | Bootstrap |
| `gameReady()` | Уведомление после интерактивности | App |
| `loadData()` | Promise строки или явная ошибка | SaveService парсит и мигрирует |
| `saveData(serialized)` | Promise подтверждения/ошибки | SaveService управляет очередью |
| `requestRewarded(placementId)` | earned / not-earned / unavailable / error | RewardService назначает награду |
| `requestInterstitial()` | request-completed / unavailable / error | AdService ограничивает частоту |
| `sendScore(integer)` | Promise подтверждения/ошибки | ScoreService выбирает метрику |
| `getLanguage()` | Promise locale | Локализация выбирает перевод |
| `subscribe(listener)` | Снимок paused/audio + функция отписки | App останавливает игру |
| `reportWarning()` / `reportError()` | Без гарантии доставки | Диагностика |
| `dispose()` | Очистка собственных подписок | Жизненный цикл приложения |

В контракте не обещай `ad-shown`, если конкретный API сообщает только завершение запроса. Название результата должно сохранять смысл исходного сигнала.

## Capabilities и профили

Опиши `cloudSave`, `rewarded`, `interstitial`, `score`, `hostLifecycle`. Отсутствие возможности не эквивалентно успеху. UI показывает доступный сценарий или понятное сообщение.

- **YouTube production:** настоящий SDK; прогресс только в облаке; lifecycle от хоста; тестовые награды запрещены.
- **Development:** отдельный явно включённый адаптер с управляемыми успехом/отменой/ошибками, тестовой памятью и пометкой TEST MODE. При необходимости тест перезагрузки использует отдельный mock backend в тестовом окружении.
- **Другая площадка:** новый адаптер и build profile, та же игровая модель; отдельное решение о доступных сохранениях и рекламе.

Выбор профиля делает entrypoint/config сборки. Не используйте hostname localhost как скрытое разрешение считать ошибку реального SDK успешной рекламой. Наличие настоящего SDK никогда не переключается на mock из-за отказа API.

## Контрактные тесты для каждого адаптера

Начальное mute; pause/resume; отписка; load success/empty/reject; save success/reject; отсутствие записи до load; rewarded earned/not-earned/reject; стабильный placement ID; два одновременных запроса; interstitial без подтверждения impression; score и его ошибка. Game-level тесты отдельно проверяют, что эти результаты правильно меняют прогресс.

## Важное улучшение относительно ASMR

В ASMR уже есть полезная граница `src/playables.js`, но `main.js`, `save.js` и `ads.js` напрямую импортируют singleton `playables`. Это не полностью сменная архитектура. В новой игре внедряй адаптер зависимостью и тестируй доменные сервисы без глобального SDK.

Точно так же текущий Vite-transform ASMR для отключения Phaser VisibilityHandler применяется ко всей сборке. В универсальном шаблоне такое поведение должно включаться только профилем площадки, которая его требует.
