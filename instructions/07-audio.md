# Звук

В ASMR финальный вариант использует один `HTMLAudioElement` для фонового OGG и переиспользуемые элементы для эффектов. Phaser Audio отключён через `audio.noAudio`; два звуковых движка одновременно не нужны. Это выбранная реализация проекта, а не обязательный способ для всех Phaser-игр.

## Инвентарь

Сначала перечисли события: успешный контакт, протирание, распыление, drop, совпадение пары, победа, монеты. Каждому назначь файл, громкость, предел частоты, длительность, правило остановки и источник/лицензию. Отдельно опиши loop фоновой музыки. Прослушай стык повтора и сочетание музыки с эффектами.

В исходном проекте пользователь сначала заменил синтезированные эффекты одной BackgroundMusic, затем попросил подключить подходящие звуки из Sounds. Итог — 22 OGG-эффекта. «Удалить другие звуки» было промежуточным запросом, не финальным требованием. `.meta` из Unity не нужны Phaser.

## Управление

```text
можно звучать = настройка игрока
              AND разрешение платформы
              AND NOT (hostPause OR userPause OR adBusy)
```

Сначала узнай состояние платформы; до этого держи звук выключенным. Mute YouTube нельзя отменить локальной кнопкой. При паузе прекрати музыку и эффекты; после resume не воспроизводи устаревший звук действия. Открытие окна паузы и host pause должны приводить к согласованному состоянию AudioService.

Браузер может отклонить autoplay. Обрабатывай отказ `play()` и повторяй после допустимого пользовательского жеста, не блокируя переходы игры ожиданием звука. Эффекты движения запускай по подтверждённому действию, а не на каждый pointermove. В ASMR применены интервал 420 мс и ограничение фрагмента 650 мс; новые значения выбираются на слух под механики.

## Проверки

Звук выключен до первого ввода при host mute; локальный toggle его не обходит; mute во время проигрывания действует немедленно; pause/ad останавливают всё; после resume нет фоновой очереди старых SFX; каждый импортируемый файл существует и декодируется. Удаляй лишние ресурсы только после сверки фактических ссылок.

После добавления аудио повторно измерь сборку. В ASMR музыка и SFX вывели её за прежнюю цель 15 МБ. Музыкальный loop нельзя считать бесшовным только из-за `loop=true`: проверяется сам стык файла.
