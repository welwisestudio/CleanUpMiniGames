# Проверка комплекта инструкций

Дата: 2 октября 2026 года.

Редакция 1.2: добавлены отдельный этап Background Remover через MCP, проверка доступности, alpha-QA и поля обработки в manifest. Обновлены AGENTS, рабочие инструкции, шаблоны и одинаковые фрагменты руководства Markdown/DOCX. Исходный DOCX отсутствовал в папке и восстановлен из внешнего ZIP; XML изменён с сохранением остальных частей пакета. Реальное удаление фона не запускалось: отдельный MCP tool не опубликован в этой сессии.

Историческая редакция 1.1: напрямую обновлён предоставленный EMPLOYEE-GUIDE.docx, сохранены его таблицы/стили, оглавление и footer. Markdown синхронизирован с текстом DOCX. Добавлены роль геймдизайнера, GitHub, Higgsfield MCP / Nano Banana 2, localhost после каждого промпта, checkpoints и общий баланс; настоящий SDK перенесён в конец. Бриф сокращён.

DOCX проверен на целостность ZIP/XML, последовательность шагов 0–12, внутренние ссылки оглавления и сохранение остальных частей пакета. Отрисовка страниц Word/PDF в этой среде недоступна; визуальная пагинация после увеличения текста не проверялась.

- Проверены относительные ссылки в авторских Markdown: цели находятся внутри переносимой папки и существуют.
- Проверены UTF-8, JSON, парность блоков кода и отсутствие встроенных base64-картинок в авторских материалах.
- Два исходных документа YouTube скопированы побайтно; SHA-256 копий совпадает с оригиналами. Ссылки и содержание внутри этих архивных документов не переписывались.
- Индекс включает 82 + 2 + 3 = 87 верхнеуровневых пользовательских блоков, с номерами строк источника; повторные запросы и уточнения сохранены.
- Числа 58 уровней / 239 стадий / 12 VIP / 58 уникальных позиций порядка получены импортом текущих данных игры.
- Версии зависимостей взяты из package-lock, не из предположения о последней версии npm.
- Выполнен существующий `python scripts/verify-package.py` исходной игры: 393 файла, корректные имена, root index.html, ZIP 15 948 849 байт, содержимое совпадает с dist.
- Проверка игровых механик и реального аккаунта YouTube заново не выполнялась. Исторические VALIDATION не выдаются за новые результаты.
- Архив шаблона сверяется по списку файлов и байтам с этой папкой после записи.

В комплекте нет runtime-кода игры, node_modules, .env и оригинальных медиа. В схемах и промптах намеренно оставлены поля для новой игры. Рабочий проект AI создаст после заполнения брифа.
