# Ошибки, причины и предотвращение

Это разбор подтверждённых жалоб/исправлений из чатов и исходников. «Проверка» в последнем столбце — правило для новых проектов, не заявление о новом выполненном прогоне ASMR.

| Ошибка | Причина / исправление в истории | Как предупредить и проверить |
|---|---|---|
| Обычный HTML UI вместо рисованной игры | Хорошая графика персонажа сочеталась со стандартными UI-формами; поверхности перегенерировали и перенесли в Phaser | Принять меню, HUD и результат как единый эталон до расширения |
| Рисованные картинки, но плохая композиция | Наложения текста, фона и наград остались после замены арта | Раздельные content bands, реальные font metrics, portrait/landscape review |
| Болотный фон | Художественная палитра не прошла субъективную приёмку | Сравнивать готовый экран с принятой палитрой, а не только prompt |
| Мыльный текст / пиксельная сборка | Недостаточная плотность текста и неявный pixelArt при HiDPI zoom | Проверять buffer/DPR/text resolution и dev/production при одинаковом масштабе |
| Чёрный кадр при resize | Изменение canvas после рендера очистило buffer | Resize перед кадром; проверять серию кадров и input после DPR-смены |
| Растянутые Memo, карточки, фотографии | Независимое масштабирование осей, неверный порядок маски/рамки | Aspect ratio, contain/cover по назначению, depth рамки |
| Обрезанные платья | Силуэт уже отрезан в исходной ячейке атласа | Осмотреть master; ремонт/перегенерация и приоритет исправленного master в packer |
| Цветные края / дырки в спрайте | Keying затронул полезные цвета или оставил spill | Alpha review на двух фонах, удаление связанного внешнего фона |
| Душ льётся из ручки, кувшин не совпадает с курсором | Sprite origin не равен рабочей точке | Хранить tip/nozzle отдельно от pivot, проверить после crop/scale |
| Ногти, тени и грязь мимо поверхности | Маска не совпала с новой геометрией арта | Общая система координат для спрайта, маски, hit и progress samples |
| Грязь по всему интерьеру | Сложный фон затруднил определение поверхностей | Изолированный объект, alpha ∩ material mask, pixel-test вне области |
| Проценты растут, ковёр не чистится | Недостаточный локальный визуальный отклик пылесоса | Менять слой под жестом, сравнить ближний и дальний пиксель |
| Грязь/пена скачет при смене стадии | Финальный/новый слой резко заменял текущий | Непрерывные слои и промежуточные кадры перехода |
| Инструменты и жемчужины слишком малы | Размер в композиции выбран без проверки пальцем | Увеличенный tray/захват, уменьшение после установки |
| Нужно отпускать расчёску между прядями | Логика повторного down управляла переходом | Продолжение одного удержания, mouse/touch сценарий |
| Волосы закрывают расчёску и направляющую | Неверный depth интерактивных элементов | Контроль порядка: арт → материал → интерактивный инструмент/guide |
| Украшение исчезает после drop | Переход состояния не сохранял частично надетый предмет | Проверять состояние после первого из пары, оба порядка установки |
| Непонятно, когда отпустить | Нет явного сигнала окна действия | Согласованный визуальный cue STOP/индикатор и подсказка release |
| Before/after перепутаны | Маска, label, направление и условие финала расходились | Единый параметр reveal и тест обоих крайних положений |
| Лишние объекты висят в поиске отличий | Размещение не учитывало композицию сцены | Авторские координаты на полках/столах; затем hit и hint |
| Премиум «без геймплея» | Золотые безделушки не дали ожидаемого содержания | Один premium-образец до 12 уровней; ценность через действия |
| Длинные premium-уровни | Слишком мелкая кисть, много мусора, медленный progress | Замер workload и живой playtest, темп на уровне обычной кампании |
| Настройки возвращают в прошлый уровень | Потеря контекста экрана возврата | Явный return state, тест settings из меню/игры/результата |
| Нельзя выйти из Bubble Garden | Ошибка маршрута вложенной навигации | Таблица переходов, Back/Escape/exit из каждого режима |
| Next не работает перед VIP | Проверка unlocked молча завершала обработчик | Route resolver: playable/offer/skip/end, прогон всех соседних переходов |
| Монеты дублируются/теряются при анимации | Риск привязки бизнес-операции к эффекту | Одна операция изменения, сохранение независимо от flights |
| Логотип прыгает при каждой странице | Пересоздавался вместе с альбомом | Отделить постоянный UI от page content |
| После lazy load сломан Skip | Menu asset registry не включал вложенные окна наград | Проверить все меню до запуска первого уровня |
| Музыка через Higgsfield не создана | Доступный инструмент был TTS; каталог недоступен | Проверять capability до обещаний, отдельно фиксировать fallback |
| Добавление аудио превысило 15 МБ | Бюджет без запаса, новые OGG | Повторять измерение; повышение лимита не называть сжатием |
| ZIP отклонён из-за имени | Пробел в Nail File.ogg перешёл в выходной путь | Валидировать весь архив, не один найденный файл |
| «Ошибка облака» при проблеме запуска | Один catch охватывал разные стадии boot | Отдельные ошибки load/parse/assets/app без содержимого save в логах |
| firstFrameReady не сработал в YouTube | Inline-script блокировала CSP | Внешний bootstrap и production под CSP |
| Visibility API остался в Phaser | Переопределение callbacks не сняло регистрации движка | Платформенный build-transform, фиксированная версия, static + runtime tests |
| Локальные SDK-тесты прошли, платформа сломалась | Mock не воспроизводил реальные ограничения | Lexical SDK, CSP, запрет storage/visibility, настоящий Test Suite |
| Документы противоречат друг другу | Инструкции этапов не помечались устаревшими | Обновлять основной статус и ссылаться на историю как на историю |

## Три наиболее дорогие ошибки процесса

**Масштабирование до приёмки.** Переделка всего UI и всех VIP-уровней была дороже проверки одного законченного образца. В новой игре сначала принимается маленький, но качественный фрагмент.

**Тестирование не того свойства.** Успешный рендер не доказывает, что пальцем удобно играть. Автотест с заранее известными координатами не измеряет время новичка. Mock SDK не доказывает совместимость настоящей CSP и облака.

**Потеря актуального контекста.** Слова «без SDK», «15 МБ» и «42 уровня» были правильны в свой момент, затем устарели. AI должен сверять текущую задачу с кодом и журналом решений, а не повторять последнее найденное утверждение в README.
