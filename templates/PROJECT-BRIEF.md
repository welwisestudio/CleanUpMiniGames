# Короткий бриф геймдизайнера

Геймдизайнер описывает основу игры своими словами. AI фиксирует её здесь, уточняет пробелы и предлагает варианты отдельно. Стиль AI извлекает из референсов. Технические ID, стек, структуру кода и контракты сотрудник не заполняет.

Принятые исходные условия: Phaser, браузер, мышь/touch, адаптивный UI; YouTube Playables SDK в конце через отдельный слой. Генерация графики — Nano Banana 2 через Higgsfield MCP `https://mcp.higgsfield.ai/mcp`. Удаление фона у спрайтов — отдельная операция Higgsfield Background Remover через MCP с проверкой доступности. После появления игры каждый результат показывается свежим билдом на localhost.

AI ведёт отдельно: план реализации, STYLE-GUIDE по референсам, технические решения и STATUS. Новые механики и темы после принятия основы может предлагать AI; изменения Core Loop и направления согласует геймдизайнер.
